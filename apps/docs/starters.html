Starter projects

Start from a small, verified project

Download a no-build HTML page or a Vite project. Both pin Nexaline UI 0.1.0-beta.1 and are inspected by the same local release gate as the packages and documentation.

Choose a starter

StarterChoose it whenTooling
No-build HTMLYou want one editable page or a server-rendered starting pointLocal web server only
Vite and npmYou want package imports, modules, development reload, and a production buildNode.js and npm

No-build HTML starter

The single-page starter loads exact-version CSS and browser JavaScript from jsDelivr, then initializes the document explicitly.

tar -xf nexaline-ui-no-build-starter-0.1.0-beta.1.tgz
cd package
php -S 127.0.0.1:8080

Download no-build starter

Production: keep the exact version, and self-host assets or add verified Subresource Integrity values when required by policy.

Vite package starter

The Vite starter imports the published CSS entry and JavaScript initializer. Hot-module teardown destroys the lifecycle before replacement.

tar -xf nexaline-ui-vite-starter-0.1.0-beta.1.tgz
cd package
npm install
npm run dev

Upgrade intentionally

Starter downloads pin an exact beta instead of the moving beta tag. Before changing the version, read the changelog and browser-support guide, update every Nexaline package together, rebuild, and run the application’s complete tests.

Review the upgrade checklist.

Release-gate verification

corepack pnpm verify:starters checks both archives, required entries, archived package identity, exact workspace version, CDN pins, and public package imports.

The documentation build copies the verified archives to dist/downloads, so the links above are tested against the same output deployed to GitHub Pages.
