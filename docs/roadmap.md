# Roadmap

After validating the foundation and vertical slice: execute the established manual accessibility protocol in its seven native environments and expand dedicated prose or live examples only where user feedback shows the searchable 38-entry component-detail catalogue is insufficient. The component reference, searchable contract details with stable deep links, automated accessibility evidence, manual review worksheet, bootable framework fixture CI, stable Chromium visual snapshots, and optional Lucide icon-data adapter are now established. Data grids, calendars, rich text, authentication, arbitrary utilities, on-demand compilation, React/Vue adapters, and Nexaline Admin remain outside core scope.

The strict original-brief audit and prioritized remaining work are tracked in `docs/specification-coverage.md`.
