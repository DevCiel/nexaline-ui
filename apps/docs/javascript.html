JavaScript

Add behavior without hiding lifecycle

Nexaline JavaScript is optional. Use it only for enhanced components, initialize the smallest stable root, and release ownership when that root leaves the page.

Choose an integration approach

ApproachBest forResponsibility
Aggregate moduleMost applicationsCall init(root) and retain its handle.
Individual constructorOne enhanced componentCreate and destroy the instance directly.
Browser bundleNo-build pagesLoad with defer, then call NexalineUI.init(document).

Initialize declarative markup

init(root) discovers dialogs, drawers, disclosures, tabs, dropdowns, and their triggers below a ParentNode. It returns an idempotent lifecycle handle.

import { init } from '@nexaline-ui/js'

const lifecycle = init(document)

// Before the initialized document or fragment is removed:
lifecycle.destroy()
Ownership: repeated initialization shares existing component instances and trigger bindings. Destroying one handle releases only that handle's ownership.

Initialize dynamic content explicitly

Nexaline does not observe the whole DOM. After inserting a fragment, initialize that fragment and keep its handle beside the code that removes it.

const fragment = template.content.cloneNode(true)
container.append(fragment)

const mounted = init(container)

function unmount() {
  mounted.destroy()
  container.replaceChildren()
}

Use a stable wrapper as the root because a DocumentFragment is empty after it is appended.

Import individual constructors

import { Dialog, Toast } from '@nexaline-ui/js'

const element = document.querySelector('#confirm')
const dialog = new Dialog(element, { closeOnBackdrop: false })
dialog.open(openButton)

const toast = Toast.show('Saved.', { duration: 4000 })

dialog.destroy()
toast.destroy()

Listen before and after state changes

Events bubble from the component root. The before* events are cancelable; completion events are not.

Before eventCompletion eventComponents
nx:beforeopennx:openDialog, drawer, disclosure, dropdown
nx:beforeclosenx:closeDialog, drawer, disclosure, dropdown
nx:beforechangenx:changeTabs
root.addEventListener('nx:open', (event) => {
  const { component, trigger } = event.detail
  analytics.track('opened', { component, trigger })
})

event.detail.component is the instance and event.detail.trigger is the initiating element when one exists.

Destroy before removing markup

  • Call the handle's destroy() when removing an initialized root.
  • Call an individually created instance's destroy() when its component is removed.
  • Destroying closes transient UI, removes owned listeners, and releases instance lookup.
  • Application event listeners remain application-owned; remove them with an AbortController or equivalent cleanup.

Use the browser bundle without a build step

<script src="nexaline.min.js" defer></script>
<script>
  window.addEventListener('DOMContentLoaded', () => {
    const lifecycle = NexalineUI.init(document)
    console.log(NexalineUI.version)
  })
</script>

The bundle exposes the global but does not initialize markup implicitly. The global contains Dialog, Drawer, Disclosure, Tabs, Dropdown, init, and version. Module imports also expose Toast and ThemePreference.
