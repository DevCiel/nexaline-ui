Manual accessibility protocol

A reproducible worksheet for native assistive-technology, browser, contrast, zoom, and physical-device review. Every result starts as Not run.

No inferred passes. Automation cannot complete this protocol. Change a result only after a named reviewer performs the task in the recorded native environment.

Result codes

Pass
Every expected result was observed.
Fail
An expected result was missed; an issue ID is required.
Blocked
The task could not be completed; record why.
Not run
No human evidence exists. This is the default.

Evidence and exit criteria

Record reviewer, date, exact OS/browser/assistive-technology versions, settings, observations, and task/environment IDs. Failures also require severity, reproduction steps, expected and actual behavior, and an issue ID.

  • Every environment is passed or has an accepted blocked rationale.
  • Every applicable task is completed.
  • No unresolved critical or high-severity accessibility issue remains.
  • Critical and high fixes receive second-reviewer verification.

Current manual status: Complete with documented blockers. Four environments passed; JAWS, macOS, and physical iOS require later native retesting before any conformance claim.
