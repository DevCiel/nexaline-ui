Optional package

Lucide icon data

@nexaline-ui/icons-lucide renders consumer-selected data from @lucide/icons. Neither the aggregate package nor core bundles an icon set.

Accessible defaults: icons are decorative and hidden from assistive technology unless decorative: false and a non-empty label are supplied. An icon never names its parent button.
import { CircleCheckBig } from '@lucide/icons'
import { createLucideIcon } from '@nexaline-ui/icons-lucide'

button.prepend(createLucideIcon(CircleCheckBig))
status.append(createLucideIcon(CircleCheckBig, {
  decorative: false,
  label: 'Complete'
}))
